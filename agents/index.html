Ready-to-run ACowork agents, packaged and signed as .agent files. Download one, import it in the Desktop App, and it joins the same Gateway as your own agents.

How to install

Three steps. No command line required.

  1. 1

    Download the .agent file

    Grab it from any card above. The file is a signed ZIP package — typically 70–170 KB.

  2. 2

    Import it in the Desktop App

    Open ACowork Desktop → Add agent → pick the file. The app reads manifest.toml and asks you to confirm the declared permissions.

  3. 3

    Talk to it

    The agent registers its capabilities with the Gateway and can be addressed directly, or reached by other agents through intent_send.

There is no browser-side install yet — ACowork Desktop does not register a acowork:// handler, so a download is as far as the web goes.

Publish your own agent

An agent is a folder: manifest.toml for identity, permissions and tools, prompts/system.md for behaviour, and skills/*/SKILL.md for repeatable workflows. No imperative code.

shell
git clone https://github.com/acowork/ACowork.git
cd ACowork
# author manifest.toml + prompts + skills, then build & sign
./dev/common/build-agent.sh examples/my-agent   # -> com.example.my-agent.agent
gh pr create                                      # -> reviewed, then listed here

Why a pull request?

Uploading from the browser would need accounts, moderation and abuse handling before there were any agents to protect against. A PR gives the same result for free: the author is a GitHub identity, the diff is reviewed, CI verifies the signature, and reverting a listing is a revert.

Read before submitting: an agent with Shell or FilesystemWrite runs a prompt you wrote against someone's real machine. Declare the minimum you need.
