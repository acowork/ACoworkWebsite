Features

What you get, out of the box.

🧩

Declarative agents

.agent packages — manifest + prompts + skills, no executable code, signed and verified at install time.

⚙️

Universal runtime

One Rust binary loads any .agent. Agents talk to LLMs directly — no proxy, no extra latency.

🌐

Distributed by default

Gateway + Node + Runtime, one protocol path. Standalone, remote nodes, or relay — same binary, no branches.

📂

AI-native PM & Doc

acowork-pm and acowork-doc as first-class services — REST + MCP, real-time multi-user editing.

🧠

Biomimetic memory

Per-agent Grafeo graph DB · 3-tier / 5-class layers · HNSW + BM25 hybrid retrieval.

🛡️

Three-layer security

Package signing + OS process sandbox + Wasmtime tool sandbox. Capabilities declared, not implicit.

Get Started

Three ways to start. Same binary.

Pick the deployment shape that matches your team — installation is the same; only the wiring changes.

A · Standalone

Local single host

Personal use, demos, edge devices. Gateway auto-spawns one local Node Agent. Zero setup.

$ ./dev/common/build_core.sh           # macOS / Linux
$ .\dev\common\build_core.ps1 -Start   # Windows

# Gateway picks up a local Node Agent automatically:
✓ Gateway   listening on  http://127.0.0.1:19876
✓ MQTT      broker    on   127.0.0.1:19875
✓ Local Node Agent enrolled (uuid=local-…)
✓ Ready. Open Desktop App →  http://localhost:5173
B · Remote nodes

Cluster

Multiple machines, one Gateway. Run heavy agents on a GPU box, lightweight on a laptop — both enroll over MQTT.

# On every host that should host Runtimes
# (GPU box, workstation, cloud VM):
$ acowork-node \
      --gateway mqtts://gateway.example.com:19875 \
      --token   $ENROLL_TOKEN
✓ enrolled as node-<uuid>

# Gateway discovers it automatically.
# Same protocol path; zero local-vs-remote code.
C · Relay

NAT'd / remote access

Reach your home Gateway from anywhere with a thin WSS tunnel — no public port, no VPN.

# Gateway side — flip the tunnel on:
$ acowork relay enable wss://relay.example.com/tunnel
✓ tunnel established · gw-id: 7f3a-…

# Desktop side — Settings → Connection: Relay
# URL: https://<gw-id>.relay.example.com
# Login with your normal account.
